# Steelgrave Private Limited website

Responsive React and Vite website for Steelgrave's stainless-steel pipe manufacturing and fabrication business.

## Local development

```sh
npm install
npm run dev
```

Production build and lint:

```sh
npm run build
npm run lint
```

## Website structure

- Home, About, Products, Manufacturing, Fabrication, Quality, Industries, Gallery, Contact, and Request a Quote.
- Product pages for round pipes and tubes, square tubes, and rectangular tubes.
- Material information pages for SS 202 and SS 304.
- Technical values and business capabilities that have not been confirmed are labelled for enquiry or owner confirmation.
- Stock photography is illustrative and explicitly identified; the Gallery uses placeholders until genuine company photographs are supplied.
- See [OWNER-CONFIRMATION.md](./OWNER-CONFIRMATION.md) for missing business information, image requests, feature limitations, and validation status.

## Enquiry handling

The quote and contact forms open a prefilled email draft addressed to `info@steelgrave.in`. Visitors must review and send the draft themselves. The website has no enquiry-processing backend, email delivery service, file upload handling, or server-side spam protection.
